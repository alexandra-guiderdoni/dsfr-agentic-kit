# Mise en avant (Callout)

Référence extraite de `../feedback-actions.md`.

---

## Callout standard
```html
<div class="fr-callout">
    <h3 class="fr-callout__title">Titre de la mise en avant</h3>
    <p class="fr-callout__text">Texte de la mise en avant avec des informations importantes pour l'utilisateur.</p>
</div>
```

## Callout avec icône
```html
<div class="fr-callout fr-icon-information-line">
    <h3 class="fr-callout__title">Titre avec icône</h3>
    <p class="fr-callout__text">Le pictogramme est ajouté via une classe d'icône sur le conteneur.</p>
</div>
```

## Callout avec bouton d'action
```html
<div class="fr-callout">
    <h3 class="fr-callout__title">Titre de la mise en avant</h3>
    <p class="fr-callout__text">Description et contexte.</p>
    <button type="button" class="fr-btn">Action</button>
</div>
```

## Callout avec couleur d'accentuation
```html
<div class="fr-callout fr-callout--green-emeraude">
    <h3 class="fr-callout__title">Titre</h3>
    <p class="fr-callout__text">Texte avec accentuation verte.</p>
</div>
```
Couleurs disponibles : `--green-tilleul-verveine`, `--green-bourgeon`, `--green-emeraude`, `--green-menthe`, `--green-archipel`, `--blue-ecume`, `--blue-cumulus`, `--purple-glycine`, `--pink-macaron`, `--pink-tuile`, `--yellow-tournesol`, `--yellow-moutarde`, `--orange-terre-battue`, `--brown-cafe-creme`, `--brown-caramel`, `--brown-opera`, `--beige-gris-galet`.
