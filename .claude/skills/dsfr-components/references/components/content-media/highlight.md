# Mise en exergue (Highlight)

Référence extraite de `../content-media.md`.

---

## Structure
```html
<div class="fr-highlight">
    <p>Texte mis en exergue pour attirer l'attention du lecteur sur une information importante.</p>
</div>
```

## Tailles

Aucune variante de taille n'existe en DSFR 1.15.2 : `fr-highlight--sm` et
`fr-highlight--lg` ne sont pas des classes officielles (vérifié dans
`dist/dsfr.min.css`). Seules les couleurs d'accentuation ci-dessous sont
disponibles.

## Highlight avec couleur d'accentuation
```html
<div class="fr-highlight fr-highlight--green-emeraude">
    <p>Texte avec accentuation verte.</p>
</div>
```
Couleurs disponibles : mêmes que le callout (`--green-tilleul-verveine`, `--green-bourgeon`, `--green-emeraude`, etc.).
