Transformer un brief en page DSFR vérifiable

Cette démo montre le chemin minimal : brief, configuration JSON, HTML généré, preuve locale.

Un agent externe peut partir du brief, lire le schéma JSON, générer la page puis contrôler les invariants locaux sans connaître l'historique du dépôt.

Le résultat est un prototype DSFR à inspecter, pas une preuve de conformité globale.

Elle prouve que le builder sait générer et contrôler une page locale. Elle ne prouve pas une conformité DSFR ou RGAA complète.

Preuve locale attendue

La commande de démo valide le schéma, exécute le builder et inspecte le HTML généré.

La preuve couvre les invariants locaux : JSON valide, page générable, ancres résolues, main et footer présents, h1 unique dans le contenu principal.

Les audits de conformité, les contenus définitifs et le comportement navigateur complet restent hors périmètre de cette démo.
