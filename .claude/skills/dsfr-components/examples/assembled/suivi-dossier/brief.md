# Brief - Suivi de dossier

Produire une page de suivi qui permet à un usager de comprendre l'état d'un
dossier, les prochaines actions et les canaux d'aide.

Contraintes :

- rester neutre, sans bloc marque ;
- utiliser cartes, tuiles, accordéon, transcription et bloc d'abonnement ;
- inclure un h1, des sections ancrables et des liens non factices ;
- préserver les garde-fous ARIA et IDs du builder.

Critère de réussite : la page générée depuis JSON est rejouable, contrôlée par
les checks locaux et suffisamment riche pour servir d'exemple produit.
