# Références partagées d’accessibilité

Ce dossier fournit les fiches communes utilisées par les skills d’accessibilité.
Il ne constitue pas une procédure autonome et aucune de ses fiches ne vaut
preuve de conformité.

| Besoin | Fichier |
| --- | --- |
| Stratégie de scan axe-core et replis | `axe-core-scan-patterns.md` |
| Sondage des noms accessibles | `accessible-name-probe.md` |
| Classification des violations | `violation-classification.md` |
| Règles de classification | `classification-rules.md` |
| Patterns de correction | `correction-patterns.md` |
| Contournement anti-robot | `cloudflare-bypass.md` |
| Critères RGAA par thématique | `rgaa-<n>-<theme>.md` |

Les fiches RGAA couvrent les treize thématiques : images, cadres, couleurs,
multimédia, tableaux, liens, scripts, éléments obligatoires, structuration,
présentation, formulaires, navigation et consultation.

Ne pas exécuter ce skill pour lui-même. Y venir depuis le renvoi d’un autre
skill et n’ouvrir que la fiche requise par ce renvoi.
