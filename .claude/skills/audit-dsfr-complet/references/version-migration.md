# Qualification d’une migration DSFR

Une différence entre la version DSFR observée et la version cible est un signal de migration, pas une non-conformité d’intégration à elle seule.

La qualification doit vérifier :

- la version réellement chargée dans le DOM et les ressources ;
- la disponibilité de la référence exacte de la version observée ;
- les notes de version et changements intermédiaires ;
- le DOM, les variantes, les états, le clavier et le responsive de chaque composant exercé ;
- les modalités de distribution, la licence et les éventuelles modifications de compilation.

Sources de suivi :

- https://github.com/GouvernementFR/dsfr/releases
- https://www.systeme-de-design.gouv.fr/

Aucun taux ni aucune conformité DSFR globale ne doit être déduit de ce seul contrôle.
